# ZTNA-VDI-SCCM-Self-Study-Lab-Guide
 
This guide breaks the course syllabus into **four practical, step-by-step labs** that you can work through in order:

1. **Lab 1 – ZTNA**
2. **Lab 2 – VDI**
3. **Lab 3 – SCCM/MECM**
4. **Lab 4 – Integration & Capstone** — combining all three technologies

Each lab follows a structured progression from **environment setup** through **configuration**, **validation**, and **troubleshooting**. Every lab concludes with a **Best Practice Tips** section before moving on to the next lab.

### Vendor Examples

The following vendor examples are used throughout the labs:

- **Lab 1:** Microsoft Entra ID + a ZTNA broker
- **Lab 2:** Azure Virtual Desktop (AVD)
- **Lab 3:** Native SCCM/MECM
- **Lab 4:** Integration of ZTNA, VDI, and SCCM/MECM, including monitoring

> **💡 Vendor Mapping Note**
>
> If you are using alternative platforms, the same concepts and steps map closely to:
>
> - **ZTNA:** Zscaler / Fortinet
> - **VDI:** Citrix / Horizon
> - **Endpoint Management:** Intune co-management
